# Nomorediet per iPhone

App SwiftUI per diario alimentare, peso e allenamento. Si installa con SideStore o Sideloadly usando un Apple ID gratuito.

- Codice: `ios/` (XcodeGen: `project.yml`)
- Compilazione: GitHub Actions, workflow `.github/workflows/ios-ipa.yml`
- Novità: `docs/CHANGELOG.md`
- Chiavi AI: inserite dall'utente in Profilo, salvate nel Keychain del telefono. Nessuna chiave nel codice.
- Kit iPhone per test con Claude Code: `scripts/iphone/README.md`
