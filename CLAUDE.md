# Nomorediet per iPhone

SwiftUI app (diario alimentare, peso, allenamento, Apple Salute) for a single user, Simone, who writes in
Italian: answer in Italian. Sideloaded with a free Apple ID (SideStore or Impactor), never the App Store.

- `ios/` Xcode project generated by XcodeGen from `ios/project.yml`; app code in `ios/Piatto`, tests in `ios/Tests`.
- Build, test and publish only through GitHub Actions (`.github/workflows/ios-ipa.yml`, macOS runner) on every
  push to `main`: .ipa at `releases/download/piatto-ios/Nomorediet.ipa`, SideStore source `…/piatto-ios/apps.json`.
  Every release needs a version bump in `ios/project.yml` (both targets) and a section in `docs/CHANGELOG.md`.
- No API keys, tokens or passwords in code or commits: AI keys live in the iPhone Keychain, entered by the user.
- Skills in `.claude/skills/`: `setup-windows` (prepare this PC, install with Impactor), `iphone-control`
  (drive the plugged-in iPhone through WebDriverAgent), `debug-salute` (Apple Health sync).
- On the phone, never type passcodes, Apple ID passwords or 2FA codes, never change Health permissions or
  delete apps/data for the user: stop and ask.
